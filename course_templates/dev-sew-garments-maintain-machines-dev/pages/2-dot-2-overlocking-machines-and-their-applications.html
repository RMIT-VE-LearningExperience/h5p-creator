Overlocking Machines and Their Applications

 

Image by pressmaster on Adobe Stock Licenced under Education License

An overlocker is an industrial sewing machine used to join fabric pieces together while trimming and finishing the fabric edge at the same time. Overlockers are commonly used when sewing knit garments because they create strong seams that can stretch with the fabric.

 

Why Use an Overlocker?

  • Creates strong seams
  • Allows stretch fabrics to move without breaking stitches
  • Finishes raw fabric edges
  • Produces a professional appearance
  • Improves production efficiency

 

Types of Overlock Machine

Different overlock machines are used depending on the fabric type, garment construction method and required seam strength.

Overlock Machines in Detail

3 Thread Overlock Machine (One Needle)

The 3 thread overlock machine is mainly used to finish the raw edges of woven fabrics. It helps prevent fabric edges from fraying or unravelling.

Common uses

  • Finishing raw edges on woven fabrics
  • Preventing fraying and unravelling
  • Serging fabric edges
  • Lightweight edge finishing

Common faults

  • Loops hanging off the fabric edge
  • Uneven stitch formation
  • Skipped stitches
  • Thread breakage
  • Fabric puckering
  • Incorrect cutting width

Stitch description

The stitch is formed using one needle thread and two looper threads.

The looper threads wrap around the cut edge of the fabric, forming a purl on the edge of the seam. This helps prevent the fabric from fraying.

 

4 Thread Overlock Machine (Mock Safety Stitch)

The 4 thread overlock machine uses two needles and four threads. It is used to construct and finish seams on knit and stretch fabrics. The stitch creates a strong, flexible seam that can stretch with the fabric.

Common uses

  • T-shirts
  • Leggings
  • Tracksuits
  • Hoodies
  • Nightwear
  • Sportswear and gym wear

Common faults

  • Wavy seams
  • Broken or popped stitches
  • Loops hanging off the fabric edge
  • Skipped stitches
  • Thread breakage
  • Fabric tunnelling or puckering

Stitch description

The stitch is formed using two needle threads and two looper threads.

The looper threads form a purl on the edge of the seam while the needle threads create parallel rows of stitching. This produces a strong, flexible seam suitable for knit and stretch fabrics.

The 514 stitch is preferred over the 512 stitch because it chains off more effectively.

 

5 Thread Overlock Machine with Chain Stitch (True Safety Stitch)

The 5 thread overlock machine uses two needles and five threads. It combines a chain stitch with a 3 thread overedge stitch to create a true safety stitch. This stitch is used where a strong construction seam and a finished edge are required in one operation.

Common uses

  • Joining garment parts
  • Side seams
  • Pyjamas
  • Trousers
  • Workwear
  • Mass production garments
  • Woven fabrics and stable knit fabrics

Common faults

  • Chain stitch unravelling
  • Skipped stitches
  • Thread breakage
  • Uneven stitch formation
  • Looper threads hanging off the fabric edge
  • Seam puckering
  • Incorrect seam width

  • Specify SPI or SPC

Stitch description

The 516 stitch is a combination stitch made up of a 401 single needle chain stitch and a 504 three thread overedge stitch.

Both stitches are formed at the same time. The chain stitch creates a strong construction seam, while the overedge stitch trims and finishes the raw fabric edge.

This is known as a true safety stitch because it provides seam strength and edge finishing in one operation.
