Introduction to Industrial Sewing Machines

 

This semester you will use industrial sewing machines to make stretch knit garments.

Each machine has a different purpose. Choosing the correct machine helps you sew safely and achieve a quality finish.

 

Why This Matters

  • Every garment in this cluster is sewn using industrial machines.
  • The correct machine improves garment quality.
  • Safe machine operation is an industry requirement.
  • This knowledge supports Assessments 1, 2, 3 and 4.

 

Machines You Will Use This Semester

Lockstitch Machine

Used for

  • Straight stitching
  • Topstitching
  • Labels
  • Some garment details

 

3 Thread Overlocker

Used for

  • Neatening woven fabric edges
  • Preventing fraying

 

 

4 Thread Overlocker

Used for

  • Sewing knit seams
  • Joining stretch fabric pieces
  • Track pants and hoodies

 

5 Thread Overlocker

Used for

  • Strong seams
  • Seaming and neatening at the same time
  • Production-style garment construction

 

 

Coverstitch Machine

Used for

  • Knit hems
  • Sleeve hems
  • Track pant hems
  • Hoodie hems

 

Buttonhole Machine

Used for

  • Buttonholes
  • Hoodie drawcord openings

PPE: Safety glasses required.

 

 

Choosing the Correct Machine

Matching the task to the machine

If you need to…

Use this machine
Sew a straight seam or topstitch Lockstitch machine
Neaten the raw edge of a woven fabric 3 thread overlocker
Sew stretch knit seams 4 thread overlocker
Create strong industrial production seams 5 thread overlocker
Hem stretch knit garments Coverstitch machine
Sew buttonholes Buttonhole machine
Apply fusible interfacing Fusing press

 

 


Assessment Requirements

Selecting and operating the correct industrial machine is a core skill for every practical task in this cluster.

  • Assessment 1: You will use these machines to complete your knit sewing workbook samples.
  • Assessment 2: Machine selection and operation during construction of the Track Pant.
  • Assessment 3: Machine selection and operation during construction of the Hooded Sweat Top.
  • Assessment 4: Machine types, uses and safe operation form part of the knowledge required for the Knowledge Quiz and Workbook.
