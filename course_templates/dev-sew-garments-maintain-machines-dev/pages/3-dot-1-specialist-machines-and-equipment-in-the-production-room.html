Specialist Machines and Equipment in the Production Room

 

Image by golubovy on Adobe Stock Licenced under Education License

This page introduces specialist machines and equipment used in the production room. Each machine has a specific purpose and must be selected according to the fabric, garment and sewing operation being completed.

Choosing the correct machine helps improve garment quality, stretch, durability and finish.

 

Safety Warning

Only operate specialist equipment after your teacher has demonstrated the safe operating procedure. Cutting machines and fusing equipment must only be used when you are trained and supervised.

 

Specialist Sewing Machines

Coverstitch Machine

Coverstitch Machine (406 Stitch)

A coverstitch machine is used to create professional stretch hems on knit garments.

It uses two needles and three threads to create a stitch that can stretch with the fabric.

Common uses

T-shirt hems, sleeve hems, leggings, shorts, track pants and hoodie hems.

Stitch description

The stitch is formed by two needle threads passing through the material and interlooping with one looper thread.

The looper thread sits on the underside of the seam and provides coverage on the bottom side only.

 

Mock Flatlock Machine

Mock Flatlock Machine (407 Stitch)

A mock flatlock machine creates a decorative stretch stitch on knit garments.

It uses three needles and five threads and is mainly used for decorative stitching effects.

Common uses

Activewear, leggings, T-shirts, sportswear and decorative stretch seams.

Coverstitch with Binding Attachment

Coverstitch with Binding Attachment (406 Stitch)

A binding attachment guides stretch binding evenly while it is stitched to a garment.

The binding must be cut to suit the attachment width and should be made from knit or stretch fabric.

Common uses

Necklines, sleeve hems, pocket edges and knit straps.

Buttonhole Machine

Buttonhole Machine (101 / 304 Stitch)

A buttonhole machine creates consistent buttonholes and reinforced openings.

It uses one needle and one thread and is used when garments require functional openings.

Common uses

Buttonholes, drawstring openings, bartacks and functional garment openings.

PPE: Safety glasses are required when using this machine.

Machine settings
  • Buttonsew: specify stitches per cycle, for example 8, 16 or 32
  • Buttonhole: specify length and width, for example 1/2 inch
  • Bartack: specify the length and width of the tack
Stitch description

Buttonhole stitches are formed to create a secure opening in the garment.

Lockstitch buttonholes are preferred where stitch security is important.

Knit shirt buttonholes are generally 1/2 inch long, placed horizontally and stitched with approximately 85 to 90 stitches.

 

Zig Zag Lockstitch Machine

Zig Zag Lockstitch Machine (304 Stitch)

A zig zag lockstitch machine forms stitches by moving the needle from side to side instead of sewing in a straight line. It can be used on woven, knit and stretch fabrics where flexibility or reinforcement is required.

Common uses

Activewear, swimwear, infantwear, reinforcement stitching and decorative stretch stitches.

Stitch description

The stitch is formed with a needle thread and a bobbin thread in a symmetrical zig zag pattern.

It is also used in some bartacking, button sewing and buttonholing applications.
